# Power BI Financial Audit & Fraud Detection Dashboard Setup Guide

This guide details how to build the multi-page Power BI reporting suite using the star-schema tables generated by the pipeline (`fact_transactions`, `dim_vendor`, `dim_category`, `dim_date`, `data_quality_summary`).

---

## 1. Data Model & Relationships (Star Schema)

In Power BI Desktop:
1. Click **Get Data** -> **Folder** or **Text/CSV** / **Parquet**.
2. Select the `data/processed/` directory.
3. Verify table names: `fact_transactions`, `dim_vendor`, `dim_category`, `dim_date`, `data_quality_summary`.
4. Open the **Model View** and establish the following **1-to-Many (`1:*`)** relationships with **Single** cross-filter direction:

| From Table (Dimension) | Primary Key (`1`) | To Table (Fact) | Foreign Key (`*`) | Cardinality | Cross Filter |
|---|---|---|---|---|---|
| `dim_date` | `date_key` | `fact_transactions` | `date_key` | 1 to Many | Single |
| `dim_vendor` | `vendor_id` | `fact_transactions` | `vendor_id` | 1 to Many | Single |
| `dim_category` | `category_id` | `fact_transactions` | `category` | 1 to Many | Single |

*(Note: `data_quality_summary` is a standalone audit table used for Page 5).*

## 2. Page-by-Page Dashboard Specifications

### Page 1: Executive Audit Overview
**Goal:** High-level executive pulse check on overall financial health, anomaly rate, and exposure.
- **Top Header:** Title `"Financial Audit & Anomaly Monitoring"`, Subtitle `"Real-time transaction integrity and anomaly scoring"`, Last Refresh timestamp.
- **Top Slicers:**
  - Date Range (`dim_date[full_date]` - Between)
  - Category (`dim_category[category_name]` - Dropdown)
  - Risk Level (`fact_transactions[risk_level]` - Horizontal buttons / Tile)
- **Row 1: KPI Cards (4 Cards)**
  1. `Total Transactions` (Formatted with comma, e.g. `100,000`)
  2. `Total Value` (Formatted as Currency `$#,##0`)
  3. `Flagged Transactions` (Count of flagged rows)
  4. `Anomaly %` (Percentage formatted with 2 decimals, e.g. `4.12%`, target badge `< 2.0%`)
- **Visual 1 (Main Left): Daily Audit Volume & Flagged Overlay**
  - Type: **Line and Clustered Column Chart**
  - X-Axis: `dim_date[full_date]`
  - Column Y-Axis: `[Total Transactions]`
  - Line Y-Axis: `[Anomaly %]`
  - Tooltip: `[Flagged Value]`, `[Critical Risk Value]`
- **Visual 2 (Right Top): Anomaly Breakdown by Detection Signal**
  - Type: **Horizontal Clustered Bar Chart**
  - Y-Axis: Signal type measures (`Duplicates Count`, `Large Transaction Count`, `Vendor Spike Count`, `Velocity Burst Count`, `Unusual Timing Count`, `Multivariate Outlier Count`)
  - Value: Count of incidents
  - Data labels: Enabled
- **Visual 3 (Right Bottom): Risk Level Distribution**
  - Type: **Donut Chart**
  - Legend: `fact_transactions[risk_level]` (LOW, MEDIUM, HIGH, CRITICAL)
  - Values: `[Flagged Value]`

---

### Page 2: Vendor Risk & Counterparty Intelligence
**Goal:** Uncover anomalous merchant behavior, sudden activity bursts, and fraudulent recipient accounts.
- **Top Slicers:**
  - Vendor Risk Tier (`dim_vendor[vendor_risk_tier]` - Checkbox)
  - Vendor Search (`dim_vendor[vendor_name]` - Search bar)
- **Visual 1 (Top Left): Top 15 Suspicious Vendors by Flagged Volume**
  - Type: **Bar Chart**
  - Y-Axis: `dim_vendor[vendor_name]`
  - X-Axis: `[Flagged Value]`
  - Color saturation: `[Anomaly %]`
- **Visual 2 (Top Right): Vendor Transaction Volume vs Flagged Ratio**
  - Type: **Scatter Plot**
  - X-Axis: `dim_vendor[total_transactions]` (Log scale recommended if high dispersion)
  - Y-Axis: `dim_vendor[flagged_rate_pct]`
  - Size: `dim_vendor[total_volume]`
  - Legend: `dim_vendor[vendor_risk_tier]`
- **Visual 3 (Bottom): Transaction Drill-Through Audit Table**
  - Type: **Table**
  - Columns: `fact_transactions[transaction_id]`, `fact_transactions[timestamp]`, `dim_vendor[vendor_name]`, `fact_transactions[category]`, `fact_transactions[amount]`, `fact_transactions[anomaly_score]`, `fact_transactions[risk_level]`, `fact_transactions[flag_reasons]`
  - **Conditional Formatting:**
    - Background color on `risk_level` or `anomaly_score` using measure `[Risk Color Indicator]` (Red for CRITICAL, Orange for HIGH).

---

### Page 3: Transaction Trends & Multivariate Outliers
**Goal:** Investigate timing anomalies, velocity spikes, and multivariate isolation forest outliers.
- **Top Slicers:**
  - Hour of Day (`fact_transactions[hour_of_day]` - Range Slider `0 - 23`)
  - Weekend vs Weekday (`dim_date[is_weekend]` - Buttons)
- **Visual 1 (Top): Hourly Transaction Heatmap / Area Chart**
  - Type: **Area Chart** or **Matrix Heatmap**
  - X-Axis: `fact_transactions[hour_of_day]`
  - Values: `[Total Transactions]`, `[Flagged Transactions]`
  - Highlights off-hours (1 AM - 5 AM window shaded/flagged).
- **Visual 2 (Bottom Left): Multivariate Outlier Scatter**
  - Type: **Scatter Chart**
  - X-Axis: `fact_transactions[timestamp]`
  - Y-Axis: `fact_transactions[amount]`
  - Color Legend: `fact_transactions[is_flagged]` (False: Cool Slate Blue, True: Hot Crimson Red)
  - Size: `fact_transactions[anomaly_score]`
- **Visual 3 (Bottom Right): Duplicate Transactions Detail**
  - Type: **Table** filtered to `fact_transactions[flag_duplicate] = TRUE()`
  - Columns: `user_orig_id`, `vendor_id`, `amount`, `timestamp`, `flag_exact_duplicate`, `flag_near_duplicate`

## 3. Formatting & Aesthetic Standards
- **Font Family:** Segoe UI or Inter.
- **Palette:**
  - Primary Slate / Dark Navy: `#1E293B`
  - Clean Background: `#F8FAFC`
  - Anomaly Alert (Red): `#DC2626`
  - Warning (Amber/Orange): `#F59E0B`
  - Standard / Clean (Green): `#10B981`
  - Primary Accent (Indigo): `#4F46E5`
